1

Create a Free GitHub Repository

Where your clean code is securely stored and connected to the cloud

  1. Go to github.com and sign in (or create a free account).
  2. Click the green "New" button to create a new repository.
  3. Enter Repository name: move-india
  4. Choose "Public" so free cloud hosting can access it.
  5. Leave "Initialize with README" unchecked, then click "Create repository".
2

Push Code to GitHub (Two Easy Ways)

Choose whichever method is easiest for you

Method A: Command Line (Fastest)

Open PowerShell or Terminal in your project directory and run:

git init

git add .

git commit -m "Move India 24/7"

git branch -M main

git remote add origin https://github.com/YOUR_USERNAME/move-india.git

git push -u origin main

Method B: Web Upload (No Git Required)

If you don't have Git installed on your laptop:

  1. On your new GitHub repo page, click "uploading an existing file".
  2. Drag and drop your project files (except node_modules) directly into the browser window.
  3. Click "Commit changes"!
3

Deploy on Render.com in 1 Click

Render will build both React and Node.js automatically

  1. Go to render.com and click "Get Started For Free" (Sign in with your GitHub account).
  2. In the dashboard, click the blue "New +" button at top right ➔ select "Web Service".
  3. Click "Build and deploy from a Git repository" ➔ connect your move-india repo.
  4. Fill in these simple fields:
    • Name: move-india
    • Region: Singapore or Frankfurt
    • Branch: main
    • Root Directory: LEAVE COMPLETELY BLANK (Do NOT enter anything)
    • Runtime: Node
    • Build Command: node build.js
    • Start Command: node start.js
    • Instance Type: Free
  5. Scroll down and click "Deploy Web Service"!
4
